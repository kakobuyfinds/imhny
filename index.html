Check sizing and QC before shipping

  1. Save the exact option. Record the listing URL, size system, color and price. Open the OopBuy option on the CAFANS product page when available, then confirm that the agent page shows the same item and variant.
  2. Compare measurements. For shoes, follow the seller’s sizing method and check whether a length refers to the foot or the insole. For a hoodie or jacket, compare flat chest width, sleeve length and body length with a garment that fits.
  3. Review warehouse QC photos. Match the color and size label to your saved option. Check both shoes for uneven soles or visible damage. For clothing, check seams, prints and fasteners. Ask for a close-up or a ruler photo if a detail matters.
  4. Compare shipping quotes for the same parcel. Use the same destination, packed dimensions and weight for each quote. Check how the carrier determines billable weight, which fees are included and when the seller’s return window closes.

OopBuy spreadsheet FAQ

What is an OopBuy spreadsheet?

It is a browsable shortlist of product links organized by category. This guide links to specific CAFANS listings so you can compare options and open the agent link when available.

Can I see the international shipping cost in the catalog?

The figures shown are estimated item prices. Ask your agent for a shipping quote based on your destination, parcel size and weight, and selected shipping line.

What if a product link opens a different option?

Check the current seller listing and compare the item photos, size chart and variant. Confirm the exact option with the agent before paying.
